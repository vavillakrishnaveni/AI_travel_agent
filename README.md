# ✈️ AI Travel Agent

An Agentic AI Travel Planner built with Google Gemini and Python Tools.

The agent decides step-by-step which tool to use to plan a complete trip.

## Tools Used
- `check_weather` - Get weather for a destination
- `search_places` - Find tourist attractions
- `search_hotels` - Find hotels within budget
- `calculate_budget` - Estimate total trip cost
- `create_todo` - Generate a packing checklist

## Setup

1. Install dependencies:

```bash
pip install google-genai
```
2. Get your API Key from Google AI Studio: https://aistudio.google.com/apikey
3. Run the agent:
```bash
python travel_agent.py
```
